# Levelz Barber Studio

The website of [Levelz Barber Studio](https://www.levelzbarberstudio.com), a
barbershop in Succasunna, New Jersey.

A hand-built static site: plain HTML, CSS and JavaScript, no framework,
deployed on Netlify.

- **Pages:** home, services, barbers, products, gallery, booking and contact.
- **Search-ready:** schema.org structured data for the shop, its services and
  products, and its FAQ, so search engines can show hours, prices and answers
  directly.
- **No secrets in the repo:** the analytics ID is injected at build time from
  an environment variable by `build.js`.
- **Performance budgets:** Lighthouse CI checks desktop and mobile on every
  pull request.

Built by [Jeffrey Montoya](https://github.com/montjeffrey) as part of a 2025
complimentary launch special. This repository is a clean snapshot of the
production site.
